# Settings reference

Every setting ned has, its default and what it does — made by `ned --doc-settings` (do not edit this file: change the setting's text in `src/ned/config/settings.nim`). Yours go in `~/.config/ned/config.json` (Settings › *Edit settings.json*, or the Settings window), a project's in `.ned/settings.json`. `ned --default-settings` prints them all as a settings file.
